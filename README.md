# CET-Succession
A political thriller strategy game where players manage Power, Loyalty, and Heat to reach the presidency.

Setup:
- Use Android Studio with an Android simulator
- Android 10+
- JDK 17 or higher
- Retrofit for AI
- JUnit 4 for testing - espresso
- Run the program from MainActivity: configure your settings to run from this file
- backend to run the AI: port 8000 --> https://github.com/moua0061/succession-ai-backend
